# DSA Friend 🧠
### Build your intuition. The syntax will follow.

> LeetCode grades your syntax. DSA Friend grades your **thinking**.

Most DSA platforms judge whether your code runs. DSA Friend judges whether your **mind** works — before you write a single line of code.

🔗 **Live Demo:** [https://laraib-builds.github.io/DSA-Friend/](https://laraib-builds.github.io/DSA-Friend/)

---

## 🎯 What is DSA Friend?

DSA Friend is an AI-powered DSA practice tool built for CS students who want to think like problem solvers, not syntax memorizers.

You pick a topic, read the concept, get a problem — then explain your approach in plain English. The AI scores your **thinking**, not your code.

Because in the AI era, anyone can write code. The real skill is knowing **why**.

---

## ✨ Features

- 🧠 **AI explanation** — understand the concept with analogies and code snippets in your language
- 🧩 **Unique problems every time** — no two sessions give you the same problem
- ✍️ **Dry run scoring** — explain your approach before coding, AI scores your intuition
- 💬 **Follow-up questions** — stuck? ask anything and get a hint without spoiling the solution
- 📊 **Session progress tracking** — problems attempted, average score, topics covered
- 🌐 **Multi-language support** — C++, Python, JavaScript, Java
- 🎯 **Difficulty levels** — Easy, Intermediate, Hard (Striver-style)
- 3 DSA topics — Arrays, Linked Lists, Stacks & Queues

---

## 🚀 How to Use

1. Pick a DSA topic
2. Pick your language
3. Read the AI explanation
4. Select difficulty and get a problem
5. Write your dry run approach in plain English
6. Get scored on your thinking
7. Ask follow-up questions if stuck
8. Try again or get a new problem

## ⚙️ Setup & Run Locally

1. Clone the repo:
```bash
git clone https://github.com/laraib-builds/dsa-friend.git
```

2. Get a free Groq API key at [console.groq.com](https://console.groq.com)

3. Open `index.html` and replace:
```javascript
const API_KEY = "YOUR_GROQ_KEY_HERE";
```
with your actual key.

4. Open `index.html` in your browser — no server needed.

## 💡 The Problem We're Solving

CS students learn DSA by memorizing solutions. When they hit a new problem, they're lost — because they never learned to *think*, only to *copy*.

DSA Friend flips this. It forces you to explain your approach before any code is written. The AI evaluates your reasoning, not your syntax. This builds the one skill no IDE can give you — **problem-solving intuition**.
